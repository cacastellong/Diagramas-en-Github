# Instrucciones del proyecto

## Propósito

Este proyecto explica visualmente el formato de gráfico de barras, tomando como referencia el primer gráfico de barras de William Playfair.

## Formatos permitidos

Los diagramas solo deben generarse en los siguientes formatos:

- `.excalidraw`: versión editable del diagrama.
- `.svg`: versión vectorial para visualizarse en la web.
- Mermaid (`.mmd`): versión textual y declarativa de la estructura del diagrama.

No se deben crear ni incorporar diagramas en otros formatos.

No se deben utilizar imágenes generadas por mapas de bits ni recursos rasterizados, como PNG o JPEG. Las representaciones deben conservar un enfoque vectorial, editable o textual según corresponda.

## Paleta de color

La paleta principal debe utilizar los siguientes colores:

- `#4FD2DB`: turquesa claro para barras, datos destacados o elementos principales.
- `#245D61`: verde azulado oscuro para textos, ejes, contornos y contrastes.

El conjunto visual debe mantener una apariencia pastel y suave. Se pueden utilizar variaciones claras o desaturadas de estos colores, siempre que se conserve suficiente contraste para leer las etiquetas, los valores y los ejes.

## Reglas de contenido

- Las tres versiones deben representar el mismo gráfico de barras.
- El tema principal debe ser el gráfico de barras de William Playfair.
- La representación debe explicar visualmente las categorías, los valores y la relación entre el tamaño de las barras y los datos.
- Debe mantenerse la coherencia entre los elementos, etiquetas y datos de los tres formatos.
- Los nombres de archivo deben indicar claramente el contenido y conservar la extensión correspondiente.
- No incluir imágenes de fondo, ilustraciones ni capturas generadas como mapas de bits.

## Dirección gráfica

La composición debe inspirarse en una ilustración editorial minimalista: formas geométricas planas, siluetas simples, contornos limpios, pocos elementos y uso intencional del espacio negativo. El resultado debe ser original y utilizar estos rasgos generales como referencia, sin copiar una obra específica ni reproducir exactamente el estilo de una artista.

- Priorizar barras sólidas, formas simples y jerarquía visual clara.
- Evitar texturas, efectos fotográficos, sombras complejas y degradados excesivos.
- Mantener una composición equilibrada y reconocible en SVG, Excalidraw y Mermaid.

## Cambios y documentación

- Actualizar el `README.md` cuando se modifique el propósito o la organización del proyecto.
- Evitar archivos generados o recursos que no sean necesarios para los tres diagramas definidos.
