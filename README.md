# Diagramas en GitHub

Este proyecto tiene como objetivo explicar visualmente el **formato de gráfico de barras**, tomando como referencia el primer gráfico de barras creado por **William Playfair**. La explicación se presenta mediante tres diagramas elaborados en formatos diferentes y publicados en GitHub.

## Objetivo principal

Un gráfico de barras permite comparar cantidades mediante barras de diferentes tamaños. Cada barra representa un dato o una categoría, y su longitud o altura permite identificar fácilmente las diferencias entre los valores. El gráfico de William Playfair sirve como referencia histórica para mostrar esta forma de organizar y comunicar información.

## Diagramas del proyecto

El proyecto está compuesto por tres versiones del diagrama:

1. **SVG**: representación vectorial, ideal para conservar la calidad de la imagen y visualizarla directamente en la web.
2. **Excalidraw**: versión editable del diagrama, útil para trabajar de forma visual y colaborativa.
3. **Mermaid**: representación textual y declarativa para describir la estructura del diagrama.

Aunque cada versión utiliza una herramienta distinta, las tres representan la misma idea central: el gráfico de barras de William Playfair.

## Objetivos específicos

- Explicar de manera visual cómo se estructura un gráfico de barras.
- Mostrar la relación entre categorías, valores y tamaño de las barras.
- Presentar la misma explicación en formatos SVG, Excalidraw y Mermaid.
- Publicar los diagramas de manera accesible desde GitHub.

## Estructura propuesta

Las representaciones pueden organizarse con los siguientes nombres de archivo:

```text
.
├── diagrama.svg
├── diagrama.excalidraw
└── diagrama.mmd
```

## Referencia

**William Playfair** es considerado uno de los pioneros de la visualización de datos. Entre sus aportes se encuentran los gráficos de barras, líneas y áreas, herramientas que facilitaron la comprensión de información económica y estadística.
